# 🎣 Fishing Game FPS (Ursina Engine)

3D гра про риболовлю з видом від першої особи (FPS), створена на базі рушія **Ursina Engine (Python)**.

---

## 🌟 Основні можливості

- **FPS-режим та плавна камера**:
  - Камера на рівні очей персонажа без відображення власного тіла.
  - Повний горизонтальний огляд на 360° та вертикальний від -85° до +85°.
  - Camera Bobbing (ефект хитання камери при ходьбі та бігу).
  - Плавне прискорення та інерційне гальмування.
- **Повна фізика та колізії**:
  - Гравець надійно взаємодіє з оточенням (стіни будинку, дерева, каміння, пірс, NPC).
  - Гравітація та стрибки з перевіркою заземлення через Raycast.
  - Присідання (`Ctrl`) зі зміною висоти камери.
- **Інтерактивна взаємодія**:
  - Центральний приціл із динамічними контекстними підказками (`"E — Відкрити"`, `"E — Поговорити"`, `"E — Магазин"`, `"E — Рибалити"`).
- **Режим реалістичної риболовлі від 1-ї особи**:
  - Закидання вудки в озеро з відображенням волосіні та поплавка на воді.
  - Витрата наживки (черв'яки, блешня).
  - Механіка очікування клювання з тремтінням камери (`camera.shake`) та підсіканням у потрібний момент (`E`).
  - Анімація вилову риби перед очима гравця (Карась, Окунь, Щука, Сом).
- **Економіка, Інвентар та Прокачка**:
  - Накопичення досвіду (XP) та підвищення рівнів.
  - Магазин рибалки: продаж риби за гроші, купівля наживки та покращених вудок (Бамбукова вудка, Спінінг, Титан Pro).
  - Журнал квестів (`Q`) із винагородами за вилов.
  - Інвентар (`I`) з детальним переліком спорядження та риби.
- **Збереження та Меню**:
  - Головне меню паузи (`ESC`) із блокуванням/розблокуванням курсора миші.
  - Збереження та завантаження прогресу (`save_data.json`).

## 🚀 Встановлення та запуск

### Варіант 1. Запуск готового Windows `.exe` (Без встановлення Python):
1. Завантажте папку або архів з релізу.
2. Перейдіть до папки `dist/FishingGame/`.
3. Запустіть файл `FishingGame.exe`.

### Варіант 2. Запуск через Python:
1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/kirilpuskaruk-svg/fishing-game-ursina.git
   cd fishing-game-ursina
   ```
2. Встановіть необхідні залежності:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустіть гру:
   ```bash
   python main.py
   ```
