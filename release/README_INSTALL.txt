Fishing Game FPS — Інструкція встановлення
==========================================

Версія: 1.0.0
Рушій: Ursina Engine (Python + Panda3D)
Платформа: Windows 10 / 11 (64-bit)

---------
ВСТАНОВЛЕННЯ
---------

1. Запустіть FishingGame-Setup.exe
2. Виберіть папку для встановлення (стандартно: C:\Program Files\FishingGameFPS)
3. Натисніть «Встановити»
4. Після встановлення — запуск через ярлик на робочому столі або в меню «Пуск»
5. Python НЕ потрібно встановлювати окремо — все включено у збірку.

---------
ЗАПУСК БЕЗ УСТАНОВЩИКА
---------

Розпакуйте папку FishingGame/ та запустіть FishingGame.exe.
Файл збережень зберігається поруч із .exe: save_data.json

---------
КЕРУВАННЯ
---------

W, A, S, D    — рух
Shift         — біг
Space         — стрибок
Ctrl          — присідання
E             — взаємодія / підсікання риби
I             — інвентар
Q             — журнал завдань
ESC           — пауза / меню

---------
ВИДАЛЕННЯ
---------

Через: Пуск → Параметри → Програми → Fishing Game FPS → Видалити
АБО через Панель керування → Програми та компоненти
Файл save_data.json у папці Документи НЕ видаляється автоматично.

---------
СИСТЕМНІ ВИМОГИ
---------

ОС: Windows 10 / 11 (64-bit)
ОП: 4 ГБ RAM або більше
GPU: Підтримка OpenGL 3.0+
Місце на диску: ~350 МБ
